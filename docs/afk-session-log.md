## SECURITY — /api/bridge/call arg-injection audit (2026-07-22)

**Found while verifying R71.** The web BFF's primary call path `POST /api/bridge/call` (`src/server.js:281`) forwards the browser's `args` VERBATIM to the gateway for any allowlisted pair (pinning only `userid`).
