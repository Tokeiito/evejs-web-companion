## Decisions made autonomously (recommended paths)

- **R53 R8 vs. density — kept ≥40px, did NOT relax R8 (the flagged decision).** The goal named this the one real tension: "very condensed" pulls toward EVE's genuinely sub-40px controls, but R8 requires ≥40px touch targets. I kept **every** `min-height` at 2.5rem/40px and condensed only *horizontal* padding, gaps, and vertical rhythm — a square button is dense and still a full touch target. I did **not** introduce any sub-40px control. **For the operator:** if you want true EVE control density (rows/buttons shorter than 40px), that is a deliberate **R8-relaxation** call for you to make — say so and it's a one-line change per control; I left R8 intact by default as the goal instructed.
- **R53 `.fit-ring-guide` kept as a 50% circle.** The one non-zero radius left after the sweep. It is a geometric guide circle for the radial fitting ring, not a rounded rectangle corner; squaring it would draw a square around circularly-placed sockets (a regression). Documented in-code and flagged here; flip to 0 if you'd rather the radial view go square too.
- **R53 condensed at the shared rules, not per component.** Tightened the page gutter, panel padding+margin, the coupled panel-head bleed, control padding, control-row gaps, divider, and tab bar — the central cascade — and left already-tight per-component inner gaps (drone/threat/hold strips, hud) alone. The goal explicitly warned against editing every component; this keeps the densification coherent and low-churn. Recommended path.
- **R53 Tailwind's dead `.rounded` utility left as-is.** The built bundle emits `.rounded{border-radius:.25rem}` only because Tailwind's scanner reads the English word "rounded" from code comments; no element uses the class, so nothing is actually rounded. I left it rather than hack Tailwind's scanner (overriding it wouldn't even remove Tailwind's literal from the bundle). Noted for the operator below.
- **R53 no server restart.** The running web server (:26500) serves `public/dist` statically and already reflected the rebuilt hashed CSS after `build:web`, so the live computed-style check needed no restart — avoiding the process-ownership trap entirely.
